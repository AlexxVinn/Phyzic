You are working on **Phyzic**, a physics-focused community Q&A platform inspired by knowledge-sharing systems like Physics Stack Exchange, with strong support for mathematical discussion, moderation, realtime interaction, and scalable community systems.

Your role is NOT to redesign or rewrite the project blindly.
Your role is to improve the platform carefully, incrementally, and professionally while preserving architecture quality and long-term maintainability.

# Project Overview

Phyzic is built with:

* Next.js App Router
* React
* TypeScript
* Tailwind CSS
* Supabase (Auth, Postgres, Storage, Realtime)

Core systems already implemented include:

* Questions & answers
* Voting & reputation
* Comments/discussions
* Draft autosave
* Notifications
* Messaging/chat
* User profiles
* Presence system
* Connection/follow systems
* Moderation/admin systems
* Reports/warnings/bans
* MathJax + Markdown + LaTeX
* Theme support

The project already has many features.
The priority is now QUALITY, CONSISTENCY, MAINTAINABILITY, and USER EXPERIENCE.
